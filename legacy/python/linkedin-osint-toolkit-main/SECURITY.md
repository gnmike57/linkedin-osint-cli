# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
responsibly:

1. **Do NOT open a public GitHub issue.**
2. Email the maintainers directly (see the repository contact information) with:
   - A description of the vulnerability
   - Steps to reproduce
   - Potential impact
3. You will receive an acknowledgement within **72 hours**.

## Scope

This project is an OSINT research tool. Security concerns include, but are not
limited to:

- Credential leakage (LinkedIn passwords, session tokens)
- Sensitive scraped data accidentally committed to the repository
- Code injection via untrusted input (company URLs, profile data)
- Dependencies with known CVEs

## Responsible Use

This toolkit is intended for **authorized security research and educational
purposes only**. Users are responsible for complying with LinkedIn's Terms of
Service and all applicable laws. The maintainers are not liable for misuse.
